# tailwind-refactor-vscode

> Official VS Code Extension for tailwind-refactor — providing real-time inline diagnostics, hover tooltips, and Quick Fix refactorings for Tailwind CSS in your editor.

---

## ⚡ Features

- 🔍 **Real-Time Inline Diagnostics**: Highlights arbitrary or non-canonical Tailwind utilities directly in JSX/TSX, Vue, Svelte, and HTML files as you type.
- 💡 **One-Click Quick Fixes (`Ctrl+.` / `Cmd+.`)**: Instantly convert arbitrary utilities (`h-[40px]`, `p-[16px]`, `bg-[#3b82f6]`) into canonical tokens (`h-10`, `p-4`, `bg-blue-500`).
- 🎨 **Tailwind v3 & v4 Automatic Scale Detection**: Automatically reads local `tailwind.config.js` or Tailwind v4 `@theme` CSS declarations.
- ⚡ **Workspace Commands**: Run `Tailwind Refactor: Scan Workspace` or `Tailwind Refactor: Fix All Workspace Files` directly from the VS Code Command Palette.
